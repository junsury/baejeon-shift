1휴대폰에 설치하기

카톡에서 링크를 누르면 카톡 안에서 열려요. 오른쪽 아래 ⋮ → 다른 브라우저로 열기를 눌러 주세요. (자동으로 넘어가기도 해요)

아이폰

  1. 사파리로 앱 주소를 열어요
  2. 아래 가운데 공유 버튼 □↑
  3. 홈 화면에 추가 → 추가
  4. 홈 화면의 파란 근 아이콘으로 열기

안드로이드

  1. 크롬으로 앱 주소를 열어요
  2. 오른쪽 위 ⋮
  3. 앱 설치 또는 홈 화면에 추가
  4. 홈 화면의 파란 근 아이콘으로 열기

2처음 가입하기

  1. 구글로 로그인을 눌러요 (평소 쓰는 구글 계정)
  2. "누구인가요?"에서 내 이름을 골라요
  3. "승인을 기다리는 중이에요" 화면이 나오면 끝! 관리자가 승인하면 자동으로 근무표가 열려요
이름을 잘못 골랐다면 다른 이름으로 다시 요청을 누르면 돼요. 한 이름에는 한 계정만 연결돼요.

3알림 켜기

승인되면 "알림을 켤까요?"가 떠요. 알림 켜기 → 허용을 눌러 주세요. 놓쳤다면 오른쪽 위 👤 → 알림 켜기.

  • 근무변경 · 대근 요청을 받았을 때
  • 내 요청이 승인 · 거절됐을 때
  • 누가 구두 합의로 바로 반영했거나, 나와 관련된 근태가 취소 · 등록됐을 때
아이폰은 홈 화면에 추가한 아이콘으로 열어야 알림을 받을 수 있어요 (iOS 16.4 이상).

4화면 둘러보기

내 근무일 · 주 · 월로 내 근무를 봐요. 일 보기에서 전날 · 같이 · 다음 근무자와 내 메모(나와 가족만 봄)를 확인해요.
팀 근무표하루: 그날 주간 · 야간 · TSO 근무자 / 한 달 · 3달 · 6달: 전체 표 (오늘 버튼, 날짜를 누르면 그 열 표시) / 편성표: 인쇄 · 카톡용 근무편성표
근태신청(휴가 · 근무변경) · 요청함(받은 · 보낸 · 수락 · 거절) · 내역(전체 기록, 취소)
대근총량팀과 내 대근 사용 가능 시간
근무요약급여 기간(16일~15일) 야간 · 공휴일 · 대근 · 휴가 횟수와 수당 시간

5근무 표시 읽는 법

주주간 08–18 야야간 18–다음날 08 비비번 (야간 다음 날) 휴휴무 휴가휴가 TTSO 08–17 지TSO 근무지원 야대근 (주황 테두리) 주근무변경 (파란 테두리) 주야주간+야간 24시간

근무자 목록에서 주황 굵은 이름은 원래 근무자가 아니라 대근 · 변경으로 들어온 사람이에요.

6휴가 · 대근 신청

  1. 근태 → 신청 → 휴가에서 날짜와 휴가 종류를 골라요
  2. 대신 근무할 사람 목록에서 부탁할 사람을 골라요 (평일 주간은 TSO 근무지원이 기본, 교대근무자 대근도 가능)
  3. 필요하면 메모를 적고 요청 보내기 → 상대가 승인하면 근무표에 반영돼요
미리 말로 합의했다면 "이미 구두로 합의했어요"를 체크하세요. 승인 없이 바로 반영되고 상대에게 알림만 가요.
주 54시간 · 하루 근무 · 주 1회 대근 · 야주야 같은 규칙에 걸리는 사람은 목록에서 이유와 함께 막혀요.

7근무변경 (맞교환)

  1. 근태 → 신청 → 근무변경에서 내 근무 날짜를 골라요
  2. 바꿀 사람과 그 사람의 근무 날짜를 골라요 (주간↔주간, 야간↔야간만)
  3. 요청 보내기 → 상대가 승인하면 반영 (구두 합의 체크도 가능)

8요청 승인 · 취소

  • 근태 → 요청함 → 받은 요청에서 승인 / 거절. 탭의 숫자가 기다리는 요청 수예요
  • 내가 보낸 요청은 보낸 요청, 처리한 요청은 수락한 요청 · 거절한 요청에서 다시 볼 수 있어요
  • 등록된 근태를 없애려면 근태 → 내역에서 취소. 상대가 아직 확인 안 한 알림은 자동으로 회수돼요
  • 내역은 근무 날짜순 / 최근 등록순으로 바꿔 볼 수 있어요

9가족과 공유하기

  1. 오른쪽 위 👤 → 가족 링크 만들기 → 보내기 (카톡으로 전달)
  2. 가족은 링크만 누르면 로그인 없이 내 근무(일 · 주 · 월)와 내 메모를 봐요. 바꿀 수는 없어요
  3. 그만 보이게 하려면 👤 → 그 링크 끊기. 바로 못 보게 돼요

?자주 묻는 질문

승인이 안 나요

관리자(메인 · 서브)에게 "가입 요청 보냈어요"라고 단톡방에 알려 주세요.

카톡 안에서 로그인이 안 돼요

카톡 안의 화면은 구글이 로그인을 막아요. ⋮ → 다른 브라우저로 열기.

알림이 안 와요

👤에서 "알림을 받고 있어요"인지 확인하고, 휴대폰 설정 → 알림에서 이 앱(또는 크롬)이 허용인지 봐 주세요. 아이폰은 홈 화면 아이콘으로 열어야 해요.

새 기능이 안 보여요

앱을 완전히 닫았다가 다시 열면 최신 버전이 돼요.

휴대폰을 바꿨어요

같은 구글 계정으로 로그인하면 그대로 이어져요. 새 휴대폰에서 알림만 다시 켜 주세요.
